Type 'show' to see the available commands.

Drico > Commands
[basics]
  exit / quit / bye - Close Drico.
  plugins - List loaded plugins and status.
  show / help - Show this command list.
[calculator]
  <expression> - Safe math (AST): + - * / % **, sqrt, abs, round, pi, e.
[concepts]
  concepts / topics - List concept topics.
[references]
  commands - List commands for a reference topic.
  references / languages - List programming reference topics.
[tools]
  list / tools / links - Show the full tool directory.
  search tools <keyword> - Search tools by keyword.
  tool <name> - Look up a tool by name.
  tool count - Print the total number of tools.
[utilities]
  base64 - Base64 encode/decode.
  bin - bin <int>
  dec - dec <0x..|0b..>
  hash - hash sha256 <text>
  hex - hex <int>
  json - Pretty-print JSON.
  regex - regex <pattern> | <text>
  timestamp - timestamp now | timestamp <epoch>
  uuid - Generate a UUID.
